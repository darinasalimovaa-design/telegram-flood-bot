# Telegram Flood Admission Bot

Python bot scaffold for two-chat applications, one-time invite links, reservations, admin moderation, and file-based storage.

## Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Put your bot token in `.env`.
3. Configure chat IDs, admin IDs, and info links in `config.json`.
4. Run:
   ```bash
   python bot.py
   ```
